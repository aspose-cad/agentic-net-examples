## Boundaries
### ✅ Always
- Use explicit types for Aspose objects when clarity is needed.
- Dispose loaded `Image`/`CadImage` instances and streams with `using` where applicable.

### ⚠️ Ask First
- Adding new NuGet dependencies besides `Aspose.CAD`.
- Changing shared templates or pipeline settings.

### 🚫 Never
- Create multi-file projects; keep each example in one `.cs` file.
- Hardcode credentials, secrets, or license keys.
- Omit required namespaces—prefer fully qualified names if ambiguity arises.

## Testing Guide
- **Build**: `dotnet build --configuration Release --verbosity minimal`
- **Run**: `dotnet run`
Success = exit code 0 and no `CS####` compiler errors.

## Domain Knowledge (CAD-specific)
- Load native DWG/DXF object models through `CadImage`; other formats use their own `Image` subtypes.
- Construct `CadRasterizationOptions` and pass it through the export options' `VectorRasterizationOptions` property.
- Preserve existing entities, geometry, and layout ownership when modifying drawings.
